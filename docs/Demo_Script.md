# Three-minute demo script

Record only after the public deployment and reviewer login have been verified.
Keep credentials, API keys, tokens and private account screens out of the video.
Use synthetic demonstration data and label it on screen. This script is a
recording plan; it is not evidence that a video has already been recorded.

| Time | Screen / action | Narration |
|---|---|---|
| 0:00-0:15 | Public web URL, then signed-in inbox | "GigBid helps a freelancer find suitable jobs and write with evidence. Every proposal and message waits for a human decision." |
| 0:15-0:35 | Settings: persona, upload, rate and weekly budget | "This account uses a clearly marked synthetic persona. I can add my own portfolio, set a minimum rate and cap weekly Connects." |
| 0:35-0:55 | Safe job detail; click Analyze | "The Analyst, Risk Assessor and Fit Matcher run in parallel. The requirement matrix shows the evidence behind each supported skill." |
| 0:55-1:15 | Live run viewer, then Proposal studio | "The writer uses source passages for experience. Verification removes unsupported claims, the Critic can request two revisions, and Compliance can block the run." |
| 1:15-1:35 | Hover/focus evidence, edit a future-plan sentence, save; dry-run preview | "This sentence links to its source. Edits are checked again. Here is the exact bid and Connects cost before anything leaves." |
| 1:35-1:50 | Refresh at pending approval; approve once; pipeline | "The approval survives refresh and restart. Approving resumes the durable graph. A repeated effect key cannot debit the local wallet twice." |
| 1:50-2:05 | Scam/injection job `syn-job-000` | "This job requests unpaid work and embeds an instruction to bypass approval. Risk flags it, and the graph skips before any external write." |
| 2:05-2:25 | Client reply, draft response, slots, approval | "The conversation graph suggests a validation response and available UTC interview slots. Sending the message still requires my approval." |
| 2:25-2:40 | Published Portfolio MCP in Inspector or supported host | "Portfolio is a standalone read-only MCP server with search, full-item resources and a screening prompt. Other MCP hosts can install it from the documented Docker/source command." |
| 2:40-2:55 | Actual retrieval chart and model comparison table | "The measured dense baseline won on our synthetic development corpus. Advanced stages did not automatically help. The repository includes raw predictions, costs, latencies and failures." |
| 2:55-3:00 | Repository/report/article links | "The report distinguishes local measurements from the instructor outcomes and human evaluations that still need external inputs." |

If demonstrating Upwork, show draft creation and the platform's separate final
confirmation. Do not show a real submission unless the account owner explicitly
authorizes it. The local simulator's automatic sample reply is labeled synthetic
and must not be described as an instructor GigSim or real client outcome.
